# 独立预设库

包可用可选 `preset_menu` 有序 ID 列表精简全局快捷菜单；预设库仍列出全部合法条目，旧 ID 照常加载。已选中的隐藏预设可继续显示当前来源，切换后不作为常驻快捷项。未声明菜单的包保持原行为。下界的“资源包默认”为四群系，“所有群系”显式开启三角洲，详见 [内置内容](../README.md#内置内容)。

## 保存与引用

主世界提供“资源包默认”、`default_caves` 与 13 个主要群系的整套预设；单群系预设 ID 与群系 ID 相同，顺序由 `preset_menu` 指定。洞穴风格为局部预设。参数定义支持 `str`，字符串随参数快照、导入导出与 Spec 原样保存，文件格式版本不变。

默认路径为模组 `Saved/presets/<名称>_<短GUID>.json`。保存、复制与导入生成完整 `p_<uuid>`；文件名默认取 8 位，碰撞逐次加长 4 位。统一清理非法字符、保留名称、尾随点／空格并规范化 Unicode，名称前缀最多 80 字符，保留中文。重命名同步文件名但保留 ID；更新参数保持路径。格式版本 1，严格字段为 `version/id/name/pack/section/params/definitions`；每个参数定义只记录 `type/page`，页面通过 `ui_model.page_id` 规范化。文件不含规则、代码、包指纹或输出设置；导入不会执行代码。

查找按 JSON 内部 ID 建立索引，以现有 `stamp`（名称／mtime_ns／大小）刷新，不要求文件名等于 ID。重复 ID 的每个文件都显示错误，原 ID 拒绝应用；损坏／重复文件用文件名哈希生成独立的 `file_<hash>` 管理引用，可单独删除，实际路径见查询条目的 `path` 字段。

整套与板块快照包含默认值。所属包必须是稳定内容包；更新从继承子包进行时保留原归属及原包的参数范围。全局保存提交所有当前参数曲线，局部保存只读取并提交本板块曲线。更新与导出使用 `storage.write_json` 的同目录临时文件与 `os.replace`；新文件先完整写入临时路径，再通过 Windows `os.rename` 或 POSIX `os.link` 排他发布，避免覆盖同名文件。重命名先发布新文件，移除原文件失败则撤回新文件；失败保留原文件并清理临时文件。

`pack:<id>` 指当前包内预设，`library:<id>` 指独立库；旧裸 ID 仍代表包内预设。包内格式／位置及 `PackDraft.save_preset` 不变。库条目可与包内 ID 同名而不冲突。导入总是生成新 ID，同名追加编号；缺失所属包可以存储，查询会显示不兼容原因。

## 加载与兼容

`api.presets(pack_id, section=None)` 返回兼容条目；整套查询排除局部条目，板块查询依据明确写出的键筛选。条目含 `ref/name/source/pack/section/sections/compatible/valid/error/digest/params`；valid 指文件格式有效，compatible 指当前包可应用。缺失源包的有效条目仍可导出／改名。管理界面使用 `PresetLibrary.entries(..., include_all=True)` 展示不兼容与损坏文件，单个损坏文件不阻断其他条目。`api.preset_sections` 保留包内查询契约。

兼容要求所属包在当前包继承链中；所应用键存在，类型及规范页面一致，值通过当前定义校验。局部只校验该板块的明确键；最终整组 resolve 还验证高度、海平面及气候等跨参数约束。局部兼容列表先检验定义和单值范围，实际加载时用当前其他参数完成组合校验；失败不改变当前状态。

整套加载以当前参数定义默认值为基础覆盖快照，局部加载在当前值上覆盖明确键。Spec v1 仍使用有效包内预设名、种子与水平区域，并显式保存解析后的全部参数。库引用／名称／digest 不进入 Spec、world_key 或任务；库文件修改／删除不会改变已导出 Spec 或已准备资源。

## UI 状态与原有数据

整套参数加载不重新创建 PackDraft，不丢弃群系、方块、地表和植被规则草稿。局部保存只修改本板块保存标记；未保存的其他参数、未应用曲线与规则仍未保存。无实际参数变化时不取消任务、不标记旧预览、不清除准备。参数有变化时沿用 `_changed` 的版本、旧结果丢弃及自动预览开关。

偏好与会话保存最后应用的 ref、名称、digest、参数快照；裸 ID 读取时解释为包内。每秒检查文件元数据变化，只刷新来源标签和选项，不重新应用。来源更新／删除后保留当前世界；重新选择才读取最新文件。整个 Saved 不搬迁、不删除，旧偏好不批量重写。

启动恢复preferences中的实际参数，不仅是整套预设的原始快照；局部覆盖和手动值一同保留。顶部“恢复默认”使用当前资源包参数定义默认值，清除整套／局部来源标记为资源包默认，但保留规则草稿、种子、水平范围和输出选择。原生选项 `defaults:all` 与板块的 `defaults:section` 都只用于界面，空来源ID可正常保存／恢复。额外session内容才显示草稿恢复提示；普通参数快照与已恢复状态相同则不重复询问。

“预设库”使用现有提示区，来源显示为“资源包／用户”。第一行“搜索预设”、输入框、整套／板块／全部范围筛选和淡红色“取消”；搜索提交（Enter／失去焦点）更新。第二行条目选择、“加载”和“高级功能”，打开时高级功能默认关闭。高级开启后显示全部条目（含不兼容），第三行展开蓝色编辑组（更新／重命名／另存）、绿色文件组（导入JSON／导出JSON）和红色删除按钮；不适用操作置灰并提示原因。下方显示所属包、范围、引用和错误。资源包预设只读，支持加载、导出、另存副本；副本保留明确参数，不强行补入其他板块。更新使用当前参数，更新／删除需确认。

筛选、选择及名称／确认表单返回保留搜索、范围、高级状态和有效选择，删除后选首个匹配条目。每次渲染的状态身份隔离已移除控件的回调，防止延迟提交替换新表单；空原生下拉事件忽略。搜索与管理操作不生成世界，只有实际加载变化沿用参数失效流程。

JSON 导入／导出分别在主线程调用公共 `mineprep.askopenfilename`／`asksaveasfilename`，文件过滤为 `*.json`。导出默认文件名清理非法字符、保留中文，并设置 `.json` 扩展名；返回空路径不操作文件。Windows 保存窗口承担覆盖确认，界面随后使用 `export_json(..., overwrite=True)` 原子写入，不重复确认；Python 接口的 `overwrite=False` 默认不变。无法打开对话框时公共接口同样返回空路径，可继续用 Python 接口导入导出。
