# 末地

资源包选择“末地”。默认生成外岛，顶部另有“主岛-虚空-外岛”预设。沿用生成预览、准备资源、放置到场景的操作。

## 取景与坐标

默认外岛没有中央岛和环形空白，任何区域都按同一个世界坐标布局生成。连片岛体、狭窄连接和小碎岛交错分布，岛缘有缺口与悬挑，底部厚薄不一。顶部保持较舒缓的高地，紫颂树只出现在外岛高地。

完整布局的中央岛位于世界(0,0)，半径默认96格，外岛约从1024格外逐渐出现。中央岛保持宽阔的主体，边缘有自然伸出的岩体和缺口。中间是没有实体的虚空，不填地板或水面。岛屿跨越边界时按输出范围裁切，不会随着取景移动。

| 想看的区域 | 生成原点X/Y | 尺寸 |
| --- | --- | --- |
| 默认外岛 | -128 / -128 | 256×256 |
| 完整布局的中央岛 | -128 / -128 | 256×256 |
| 完整布局的远处外岛 | 1120 / -128 | 256×256 |
| 中间虚空 | 480 / 480 | 64×64 |

面板的水平X/Y对应MC的X/Z，MC高度Y对应UE高度Z。原点(0,0)位于生成区域角落；查看中央岛时需要把范围放到主岛中心两侧。切换包或预设不会改写你的取景范围。

## 脚本

```python
from mods.WorldGenerator import api

outer = api.spec('end', region=(-128,-128,256,256))
main = api.spec('end', 'full_end', region=(-128,-128,256,256))
world = api.generate(main)
print(api.check(world))
api.snapshot(world, 'end_main.png')
```

先生成小范围确认，再按需要扩大。三维实体按现有分块和高度带处理，不保存整个世界体素。纯虚空可以正常生成；模型数量为0不表示报错。

## 调整景观

- `end.layout`：`outer`为默认外岛，`full`为完整布局，通常直接选顶部预设即可。
- `end.center_x / center_z`：中央岛中心，可整体移动主岛、柱体、祭坛及环形虚空。
- `end.main_radius / outer_start`：主岛半径与外岛起始距离。
- `end.scale / density`：外岛尺度与疏密，控制连续岛屿场中的岛体大小和留白；密度为0时不生成外岛。
- `end.height / relief / thickness`：浮岛高度、外岛高低变化和实体厚度。世界上下界只做裁切，改变它不会重新生成物理边界。
- `chorus.enabled / density / spacing / max_slope`：紫颂树开关、候选概率、间距和坡度。八款树形复用原生连接与花朵模型，根部检查真实末地石支撑；支持植被分布与留空遮罩。
- `chorus.whole_tree`：面板“整棵紫颂树”，默认开启。关闭后逐方块输出；两种模式共用树形、选址和整棵避让，逐方块模式在输出边界裁掉范围外的方块。
- `monuments.pillars / portal`：中央岛屿中的黑曜石柱与返回传送门祭坛开关，不受植被遮罩影响。

主岛含十根不同高度的黑曜石柱，柱顶保留基岩；中央基岩祭坛保留静态传送门表面。末影水晶暂不生成，待有独立模型后再加入。不会执行传送或生物行为，也不会改动关卡天空和灯光。末地城和末地船暂未加入。

## 紫颂树的生成

八款模板高度分别为8、10、12、14、16、18、21、24格。参考Minecraft的`ChorusFlowerBlock.growTreeRecursive`，每次侧向只生长一格，通常再向上生长2～5格，然后从新枝端继续分叉；根部竖段稍长，最后一段可能缩短。枝条在不同高度停止，末端放紫颂花，并避开已有枝条，形成紧凑、不规则的多级树冠。两种输出模式共用树形；每格根据相邻方块写入六个连接状态，调用原生紫颂树与花朵模型烘焙。这是面向取景的固定模板，不复现游戏种子的随机序列。

生成世界时，在外岛高地按候选间距、密度和种子选择位置，从真实体积中寻找末地石顶面，再检查坡度、碰撞及两个遮罩。每个位置选择一款模板并旋转0／90／180／270度。整棵模式复用整株网格；逐方块模式复用按连接状态生成的单格网格，继续使用ISM／PCG／Niagara批量放置，不为每一格重建模型，也不会变成每格一个Actor。

0.64.3修正公共解析中紫颂树上下连接部件的旋转，消除枝条转弯处的空隙。需同步公共文件`mc_structure.py`与`mc_mesh.py`，整体重载Mineprep后重新准备资源并放置；已放置的旧模型不会自动替换。

## 预览与资源

参考概览使用二维岛屿布局，并明确标记为参考；真实实体还会经过三维噪声塑形，因此边缘与概览略有差异。虚空显示黑色背景，完整景观预览和体积剖面也使用同一底色。方块预览颜色和体积预览的环境亮度已提亮，只影响离线图片，不改变UE材质、天空或灯光。

末地复用配置中的MC资源包，只附带传送门表面的小型JSON模型，不复制原版贴图。紫颂树需要本版本公共方块解析；给其他工程更新时，也要同步Mineprep的`Content/Python/mc_structure.py`，然后整体重载Mineprep。
