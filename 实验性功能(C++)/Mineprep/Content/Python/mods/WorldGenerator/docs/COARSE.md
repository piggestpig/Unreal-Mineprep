# 大世界的分辨率、固定LOD与留空

世界范围页的“分辨率”可选 1、2、4 格。默认 1 格保留完整生成行为；2／4 格直接生成更大的地形块，适合减少远景布景的实例数。0.69.0 起支持标准高度／体积地形包，包括主世界洞穴、地下水、湖海连接、下界及末地。0.70.0 起框选LOD和留空支持主世界干洞穴、下界和末地，0.71.0 起也支持地下水及湖海连接。

```python
from mods.WorldGenerator import api

spec = api.spec('vanilla', seed=42, region=(0, 0, 2048, 2048), cell_step=4)
world = api.generate(spec, execution='processes', workers=4,
                     max_instances=25_000_000)
api.snapshot(world, 'delivery/coarse_world.png')
```

`region` 仍是实际世界范围，`cell_step` 只改变 MC X／Z 方向的地形采样和方块尺寸。MC Y 高度仍按一格生成；海平面、噪声尺度、放置位置与厘米换算保持原单位。网格对齐世界坐标零点，负坐标向下取整，区域边缘不足一块时裁短，不越界。

| 内容 | 1 格 | 2／4 格 |
| --- | --- | --- |
| 地形、水面 | 完整逐列采样 | 按世界对齐网格采样，生成真实尺寸的方块 |
| 洞穴 | 逐格三维壳 | 2×2×1／4×4×1，保持一格竖向细节 |
| 地下水、湖海连接 | 按实际洞穴校验 | 按实际粗占据校验；地下水面保留单位格稀疏输出，再水平合并 |
| 地面积雪 | 原覆雪层数 | 覆雪层数大于零时，把实际露出的地形顶格替换为雪块，不增加高度 |
| 草、花、灌木、仙人掌、海草、海带 | 遵从原参数 | 内置定义以 `detail_only: true` 省略 |
| 下界小菌、菌索、下界苗、零散火 | 遵从原参数 | 内置定义以 `detail_only: true` 省略 |
| 菌树、紫颂树、萤石、化石 | 遵从原参数 | 保留完整模型；支撑与净空查询实际粗几何 |
| 末地中央祭坛（0.71.2起） | 单位格基岩与传送门面 | 保留相同细节，按范围及留空列裁切 |
| 树木、冰山、冰刺、石头、倒木 | 遵从原参数 | 保留原有模型细节，根据粗地形判断落地和避让 |
| 整树模板中的树冠积雪 | 遵从原参数 | 保留模板规则 |

粗区不修改保存的小植物参数，切回 1 格后重新生效。积雪总开关、层数零关闭和水面冻结开关仍有效。雪块会使台阶侧面也呈白色；河岸、轮廓和树木落点可能变化，需按镜头选择精度。

0.71.1起，粗顶块按实际覆盖列判断暴露和露天状态。只有判定不一致的粗块才局部拆成单位格，遮挡部分保留原材质，露出部分接受覆雪等处理；全露出或全遮挡的块保持粗尺寸。拆分不改变基础实体覆盖，但局部实例数可能增加，随后仍使用原合并器。`surface_split_boxes`和`surface_split_extra_cells`统计表面阶段的拆分量。贴图沿用材质中以Actor为原点的整体坐标对齐，不增加UV补偿。

`WorldSpec.cell_step` 默认 1。旧 JSON 无此字段时按 1 格加载；默认值不额外写入 JSON，非默认值进入生成和资源身份。面板精度随范围偏好和会话保存，切换群系预设或内容包不重置；开启主世界洞穴、地下水和湖海连接均保留精度。`api.describe(pack)['capabilities']['horizontal_steps']` 与面板、请求校验共用能力判断，`fixed_regions` 单独报告框选LOD能力。

```python
spec = api.spec('vanilla', seed=42, region=(-64, -64, 128, 128), cell_step=2,
                params={'caves.enabled': True, 'groundwater.enabled': True,
                        'groundwater.connect_surface': True})
world = api.generate(spec)
cut = api.section(spec, axis='z', at=0)  # 占据剖面覆盖整个粗方块
api.snapshot(world, 'delivery/coarse_caves.png')
```

洞穴仍采用解析背景、物理尺寸 tile、32 格高 slab 和局部变化块，六邻接在采样网格上剔除隐藏方块。支撑、洞口避让、占据剖面和水体检查均将 X／Z 查询映射到同一个粗格原点。噪声尺度、洞穴半径、材料厚度和水位保持真实格单位；不会把水位吸附到网格，也不增加水模型偏移。

连接探测先查询未挖通的基础洞穴密度；候选通道先形成完整粗格的开口，再验证封闭性、唯一水源及泄漏，批准后才写入最终密度。只在有界水体验证窗口展开布尔占据，不建立整片细格三维几何。粗化可能使横向窄通道消失，改变洞口和水体的位置、数量；被拒绝的候选不会强行铺水。洞穴布局、密度、地下水和连接缓存区分步长，宏观地形／水系规划继续复用。0.66.1 修复了同一进程切换精度时复用错误洞穴布局的问题。

`world.heights`、`biome_ids`、`columns`、`water_levels` 等二维数组仍覆盖原世界范围，粗采样值按覆盖区域展开。`world.arrays.sizes` 保存每个实际几何块的 XYZ 尺寸；合并器接受这些尺寸并继续无损合并，不把它们展开成完整逐格几何。ISM、PCG、Niagara 沿用现有位置／缩放载荷，BCT 仍按真实世界范围采样。

体积地形共用现有三维壳。`VolumeQuery` 按同一粗格查询实际占据，显式指定基础密度字段仍可用于规划；高度裁切不会制造支撑面。粗模式及混合分区的 `landscape_surfaces` 行为 `(x,y,z,block_id,width,depth)`，统一1格仍为原四列；预览按尺寸覆盖完整粗面。表面处理器的 `SurfaceBatch.sizes` 提供实际XYZ尺寸，`None` 表示单位格。下界熔池先形成实际开口与封闭边缘，再输出单位格稀疏水面；跨精度边界时在有界窗口检查完整采样覆盖和每条物理岸边，留空边缘不通过封闭验证时拒绝候选。水位与零模型偏移保持原约定。

`stats['solid']` 和 `cavity_volume` 按实际覆盖面积累计真实格体积；`geometry_voxels`、`density_queries`、`groundwater_samples` 与连接采样计数表示实际求值工作量。粗精度收益应以生成／合并耗时和最终实例数衡量，不能用理论采样比例代替实测。洞穴关闭时继续走二维快速路径。

以上是不启用LOD时的统一精度功能。诊断预览可离线查看；UE 的贴图平铺、边界与画面由用户验收。

## 固定LOD与留空

0.67.0 起，一次生成可同时包含精细核心和一档外围精度。分区在生成时固定，动画摄影机移动不会切换精度。

```python
spec = api.spec(
    region=(-512, -512, 1024, 1024),
    cell_step=4,
    core=((-62, -92), (88, 21)),
    core_empty=False,
)
world = api.generate(spec)
background = api.generate(spec.replace(core_empty=True))
api.snapshot(world, 'delivery/fixed_core.png')  # 含分区图
```

`core` 是绝对 MC X／Z 方块坐标，与 `region` 原点同一坐标系；面板使用 UE 水平 X／Y 名称。两个端点都包含在内，可反向输入，上例尺寸为151×114格。内部转换为半开 `Region`。`core=None`、`core_empty=False` 是旧配置的默认值，不启用时 `cell_step` 仍控制全图。

| 模式 | 核心与输出范围的交集 | 外围 |
| --- | --- | --- |
| LOD精细 | 地形／水面逐格，保留原小植物与景观 | `cell_step=1/2/4`，建议4；沿用粗模式规则 |
| LOD留空 | 全高不输出地形／水面，不产生新景观锚点 | 继续生成地形、水面和完整景观，允许外围树冠等伸入核心 |

范围页勾选“启用LOD”，输入“LOD边界点A／B”，按需勾选“LOD留空”；“分辨率”指定框外精度。默认边界点为 `(0,0)`、`(512,512)`，包含两个端点；保存绝对坐标，启用、移动或扩大生成范围都不会移动边界点。未吸附到粗网格的LOD边缘会精确裁短外围粗块。

0.72.0的地图操作为中键平移、右键选择LOD（紫色半透明）、普通页面左键选择留空LOD（纯白）；自定义页面的左键用于[绘图](PAINTING.md)。两种框选修改同一个选区，每次替换旧区域。拖动时只显示临时框、绝对坐标和实际格数，松开对应按键才应用参数；反向拖动有效，终点越界时裁到地图边缘。丢失捕获或切换视图／生成范围会取消临时框。

0.68.1 起，右键框选只要当前分辨率为1格，就自动改为2格，无论是否已有LOD；2／4格保持不变。中键首次创建时仍默认2格，后续中键框选保留当前分辨率。清除选框只关闭LOD，保留原边界点；“恢复默认”则禁用LOD、关闭留空、重置边界点为 `(0,0)`、`(512,512)`，并将分辨率恢复为1格，种子、生成范围和输出设置保留。手工修改边界点和模式会同步叠加框，LOD变化不会重置地图缩放和平移。已有偏好不因升级被覆盖。

框选适用于各包的景观、地表、植被、群系、高度、温湿度、水系及固定分区等地理俯视图；自定义图像／遮罩和洞穴组图继续使用平移缩放。下界景观按当前预览高度显示剖开的楼层，也可在该俯视图框选。相同范围的旧地图可用于重新框选；旧预览与当前生成范围不同时会隐藏选框并提示刷新。松开后遵从现有自动概览规则，超过512²或关闭自动概览时仍需手动预览。框选保留地下水和湖海连接开关。

完整核心坐标随偏好、会话和 Spec 保存，生成时只取交集。核心在范围外等同全外围；覆盖全图得到全精细或无地形／水面的结果。留空仍可接收外围锚点的跨界完整景观，不能把“留空”理解为排斥所有模型的净空遮罩。

分区能力按标准height／volume几何配方判断，不依赖包名或继承vanilla。主世界洞穴、地下水与湖海连接、下界和末地可直接使用相同框选与参数；切换内容包保留已保存的开关、边界点、模式和分辨率。`api.describe(pack)['capabilities']['fixed_regions']` 表示包是否提供基础几何能力，具体参数仍在每次请求时校验。

0.71.0起地下水和湖海连接按实际混合占据验证：基础洞穴按各区步长采样，连接先形成裁短后的完整候选开口，再验证封闭性和唯一水源，批准后应用于最终几何。验证窗口仍独立于普通输出裁切。留空区是真实开口，地下水或连接若向其中泄漏则拒绝该候选，不添加封口墙；普通湖海水面仍按列裁掉核心。水位不量化，水面沿用单位格稀疏输出与现有合并器，模型offset保持零。

地形接缝保证闭合，不混合高度、不增加过渡圈。二维柱壳以最低相邻顶面确定侧壁；三维壳中，粗面只有在整条物理邻边都被实体覆盖时才隐藏，细侧读取实际粗邻居。局部洞穴变化盒按外围步长保守扩展，防止32格块边界漏出邻面。台阶、洞口、河岸轮廓和水面位置可能在精度边界变化。景观按锚点确定归属，候选、竞争、支撑与净空共用同一分区参考；完整模型不沿精度边界切碎。`detail_only` 小景观只在精细核心产生锚点。连续冰原按列裁掉留空部分，独立冰山遵从锚点规则。

留空是输出裁切：`heights`、`columns`、`water_levels`、`wet_mask` 保留有效参考，宏观水系只规划一次；`water_mask` 和基础地形占据反映裁切结果。普通景观预览允许显示伸入的树冠，`api.section` 显示实际基础地形占据。面板“固定分区”图显示绿1格、黄2格、蓝4格、黑留空、白线为核心边界；高度／群系等参考图继续保留核心信息。离线单图可用 `adapters.preview.write_views(world, directory, names=('lod',))`。

`stats['lod_cells']` 记录各精度的实际水平覆盖格数；`lod_step_N_solid` 按覆盖面积累计实体体积，`lod_step_N_terrain_instances` 是对应分块的合并前地形单元数。最终实例数应在现有合并后统计，包含整模型。留空会露出外围内侧壁，裁掉的面积与实例减少量不会严格成比例。

鼠标框选已写回同一绝对角点参数。混合精度干洞穴已经接通；地下水和跨区湖海连接下一阶段独立实施与验收。多圈固定精度仍按实例数与画面再评估，始终保持静态分区。
