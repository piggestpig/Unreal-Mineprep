# 地图绘图

在自定义页选择“高度图”“植被分布”“留空区域”或“群系分布图”，即可在左侧地理俯视图上用左键绘制当前图层。不必先导入图片，也不必先生成世界。没有匹配范围的预览时，使用空白底图；切换到剖面等非地理视图不能绘图。前三项为连续数值，0.76.0新增的群系图保存离散类别。

中键平移、滚轮缩放、右键框选精细LOD。普通页面的左键用于矩形留空LOD；自定义页的“留空区域”画笔则只清理植物和景物，两者作用不同。

## 三种数值

- **高度图**：新建画布为零增量，首笔自动启用“叠加到主地形”，正值抬高、负值降低，默认目标+16格。编辑已有高度图时保留当前模式；绝对模式的目标表示高度，叠加模式表示增量。仍限于支持高度图的主世界高度链，不为下界／末地新增高度图支持。
- **植被分布**：初值1保持原密度，目标默认0；0不生成，灰值减少候选，不会强行在不适合的位置种树。绿色覆盖表示密度降低。
- **留空区域**：初值0，目标默认1；大于等于0.5的地方排除参与净空的完整植物和景物。粉色覆盖表示净空强度，地形和水面保留。

高度覆盖用暖色表示非负值、冷色表示负值。覆盖颜色与透明度只用于显示，不是实际高度／密度，不从RenderTarget回读生成数据。“显示绘图层”可以暂时隐藏覆盖，鼠标提示显示当前世界坐标和真实数值。

## 笔刷与保存

数值笔刷默认直径32格、硬度50%、强度100%。直径按实际世界格数计算，与显示缩放和地形LOD分辨率独立；细于输入像素的笔刷至少绘制鼠标下的一个像素。同一笔重叠处不重复积累强度，再画一笔可以继续向目标值混合。快速拖动补齐中间笔触；离开画布断笔，回来不连一条跨界线。

群系笔刷选择本地化群系名称，直接写整数类别；“自动群系（擦除）”写回透明输入。固定硬边覆盖，隐藏硬度、强度和数值控件；切回数值图仍保留其原设置。未导入图片时新建透明画布，已导入图先按色板／容差分类一次。叠加层用地图显示色，实际生成仍保留原水域；细节见[群系图](BIOME_MAP.md)。

一笔松开后自动保存，调用一次变更流程并作废旧准备结果。绘图中不生成世界、不写文件，自动概览继续遵守开关及512²限制；植被和净空的实际效果要生成完整预览才能观察。切换页面、图层、视图、范围或失去鼠标捕获会取消未提交笔画，笔画中不缩放。

0.72.2起，笔画完成、撤销／重做和保存沿用现有右侧控件，只刷新输入状态和提示；首次保存隐藏新画布提示，不再每笔清空、重建笔刷面板。页面／图层切换或展开映射等布局变化仍按原规则重建。

“撤销／重做”按整笔处理，历史只保存受影响的64²数据块，预算64MiB；单笔超过预算时只保留这一笔。修改后新画笔会清除重做记录。“保存绘图”可重试写入；失败时保留内存编辑并阻止未保存版本进入生成。

工作文件位于`Saved/paint/`，数值图为float32 EXR，分类图为8位RGBA PNG与同名`.palette.json`，通过既有文件输入接入，不改变WorldSpec格式。导入图像／Texture2D首次绘制时建立副本，原文件和资产保留；高度映射固定为实际格数。高度支持导出EXR，遮罩还可导出16位PNG；群系导出PNG和稳定ID色板，重新选图时自动装载同名色板。

新画布覆盖创建时的世界范围，默认每格一像素，最长边最多2048像素；导入图保留原始尺寸和现有像素总量限制。之后移动／扩大生成范围不会移动或拉伸已有画布。需要重新绑定时使用原有覆盖原点／尺寸或“使用当前世界范围”；高度图在覆盖区外仍沿用既有边缘延展规则。

完成的工作图和笔刷设置随偏好恢复，撤销历史不跨面板重启。分享时携带工作EXR或PNG／配套色板并重新绑定路径；保存包／预设本身不会打包图片。UE中的覆盖颜色、鼠标捕获、缩放对齐和拖动手感仍需实际验收，离线图只验证数据和几何。

## 直接RT预览（0.72.1）

NumPy继续保存真实数值，GPU叠加层使用两个固定RG32F渲染目标交替更新；普通笔触和正常松开不再编码PNG或导入临时叠加纹理。0.76.1起取消30Hz时间上限，每个Slate帧集中按顺序提交待处理笔画；鼠标事件保留完整轨迹，没变化不提交。只有局部矩形及上次差异区需要写入；两区相距较远时分开更新，避免覆盖中间大片空白。同一笔的最大覆盖量保存在RT中，保留软边、强度、擦回和重叠不加深的效果。实际更新频率受编辑器帧率和绘制耗时影响，不保证固定60Hz。

来源文件时间／Texture Source ID只在载入、输入配置变化、开始新笔画以及保存后检查，逐帧显示与连续鼠标移动不再查询。外部修改会在下一笔开始时识别；未保存笔画继续优先保留内存数据。

0.76.0首次使用会在`/Game/mc/WorldGenerator/_PaintPreview/v2/`自动建立并编译两个母材质，之后复用。尺寸相同的画布复用RT和动态材质；两个RT在512²时约4MiB、2048²时约64MiB，不含输入同步纹理及引擎开销。关闭面板会释放RT。首次载入、撤销／重做、重新显示隐藏图层、切换图层或输入时允许从NumPy同步一次；同步使用两张单通道float32 EXR，以免UE的多通道浮点导入降为16位。分类图仍使用这两张RT和整数精确覆盖，另载入一次小色表显示群系颜色；编号不经过RGBA16F。日常绘图不回读GPU，正常世界概览的底图导入仍保留。

材质准备或绘制失败会显示“绘图显示失败”，数值编辑和保存仍保留，不自动退回逐笔纹理导入。UE编译、数值误差及512／2048画布提交检查见[校验片段](../examples/paint_rt_check.py)。脚本只创建预览材质和临时RT，不修改关卡；其中GPU读回仅用于校验。CPU提交耗时不代表GPU执行耗时，颜色和实际拖动体验由用户在UE验收。

该校验已增加分类笔画、切换群系、擦除、取消和撤销重做的数值检查；`measure(512, kind='biome_map')`可测分类笔画的CPU提交及普通笔画是否重新导入纹理。校验脚本需用户在UE中运行，离线HLSL编译不代替这些检查。
