# 群系分布图

用颜色分区图指定森林、沙漠等陆地群系的位置。0.76.0支持按群系名称直接绘制、擦除和整笔撤销／重做；也可导入PNG并使用独立标记色、可编辑映射和颜色容差。适用于主世界及其派生包。

## 在面板中使用

1. 打开“自定义 → 群系分布图”，选择PNG。首次选择按当前世界范围绑定。
2. 使用红绿蓝等简单标记色。在每行颜色控件和群系下拉框中编辑映射；底行选择颜色与群系后点击“添加”，“删除”移除相应映射。
3. 点击“查看群系”，现有群系视图显示应用结果；生成景观时地表材料和植被使用同一选择。
4. 改变生成范围不会拉伸图片。“使用当前世界范围”可显式重新绑定。

默认红色对应森林、绿色对应草原、蓝色对应沙漠；其余陆地群系按包内顺序分配黄、青、品红及六种半亮度颜色。12种候选色使用255和128亮度；黑白默认不分配。超过默认色数时继续添加自定义颜色，不限制为12种群系。

“恢复默认色板”重置映射，地图显示颜色或语言变化不会改动已配置的标记色。下拉框显示当前语言名称，配置保存稳定ID，例如`forest`；映射修改只影响本次输入，不修改资源包中的群系定义。移除全部映射表示所有像素沿用原选择。

路径、色板、容差、启用状态和映射范围随操作偏好／草稿会话保存。图像仍是外部文件，保存不会改写原图；移动配置时需要重新指定文件路径。旧Spec及已有文件输入的旧操作设置没有容差字段时按0读取，保留其显式色板和精确匹配行为；新建输入默认32。

## 直接绘制群系

在该页的“地图绘图”下拉框选择森林、沙漠等群系，左键绘制；选择“自动群系（擦除）”恢复自然／预设选择。无需先导入图片，首笔在当前世界范围新建透明分类图。已导入图片也能继续绘制，保留其尺寸和固定映射范围。

首版使用硬边分类笔刷，只提供直径和显示开关，不提供数值、硬度或强度。直径默认32格，按世界格数计算；类别不插值、不混合。中键平移、滚轮缩放和右键框选LOD沿用原操作。快捷拖动会补齐中间笔触，撤销／重做按整笔处理，取消笔画恢复落笔前状态。

拖动期间叠加层按群系的地图显示色显示输入类别，鼠标提示显示群系名称；实际生成仍执行原水域保护。落笔后按原自动概览开关刷新效果，高度、水系及地表／植被的其他规则继续生效。

完成笔画后自动写入`Saved/paint/`中的PNG副本及同名`.palette.json`，并启用该输入；也可点击“保存绘图”重试，或导出PNG和配套色板。重新选择PNG时，如存在同名色板，会验证并装载其稳定ID映射。分享时请一并携带两个文件；范围仍在面板／Spec中保存。撤销历史不跨面板重启，当前群系选择随笔刷偏好保存，不受语言变化影响。

导入图首次进入画布时，按现有色板和容差分类一次；未识别／透明像素在副本中变为透明，识别出的类别保存为规范标记色，工作输入切换为容差0。原始图片保留。新选中的群系若尚无标记色，会自动分配未使用颜色；不会被12种候选色限制。正常保存后修改来源、色板、容差或映射，会重新载入画布并开始新的绘图历史。

## 图片与选择规则

- 使用8位PNG，支持RGB／RGBA、调色板PNG及灰度同色。按解码后的RGB字节识别，不进行色彩空间换算；原生颜色控件的线性值通过现有工具换算为标记色字节。
- 容差默认为32：每个通道偏差均不超过该值才是候选，再选RGB平方距离最小的已配置颜色；等距或没有候选时沿用原群系。0为精确匹配。
- alpha为0、未匹配颜色和图片覆盖范围外的像素，沿用原群系选择。图片本身可只画需要覆盖的部分。
- 使用最近邻类别采样，不插值群系ID。调整图片大小时同样应使用最近邻并关闭边缘抗锯齿。
- 容差修复小色差，不能恢复混色丢失的类别信息。暗红可能是另一群系，也可能是半透明红笔画在黑底上的结果；建议外部绘图使用不透明色块。内置分类笔刷直接写类别，不对群系编号混合。
- 数组／图片按`[Z, X]`排列，顶行对应映射范围的最小MC Z。面板原点采用UE水平X／Y，分别对应MC X／Z。
- 地形高度和水系先按原规则计算。分布图覆盖之后的陆地群系选择，地表材料、植被与参考地图共用这一结果；不根据图片重新塑造山川或规划河流。
- 已有湿水面，以及`ocean`、`frozen_ocean`、`river`、`lake`、`pond`群系保持原选择。这些ID不能作为第一阶段的色板目标。
- 指定颜色的优先级高于陆地单群系预设；图外仍沿用该预设。坡度、气候、支撑、积雪开关和植被密度等原规则继续生效。

预览显示已匹配、未匹配和透明像素数。`world.stats['biome_map']`另包含输入尺寸、色板、容差和`classify_seconds`（当前进程绑定时的识别耗时，不含读图／解码）。三类像素互斥且总和等于图片像素数；匹配数是源图识别结果，实际覆盖还受原水域保护限制。

## API

```python
from mods.WorldGenerator import api

spec = api.spec(region=(-64, -96, 128, 128))
spec = api.with_biome_map(
    spec, r'E:/maps/biomes.png',
    palette={'#ff0000': 'forest', '#0000ff': 'desert'},
    region=(-64, -96, 128, 128),
    tolerance=32,
)
overview = api.overview(spec)
world = api.generate(spec)
print(world.stats['biome_map'])
restored = api.WorldSpec.from_json(spec.to_json())
ordinary = api.with_biome_map(spec, None)
```

省略`palette`时使用默认标记色板，见`api.describe()['biome_map']`；其中`marker_colors`列出12种候选色，`palette`只列出已经分配到该包群系的颜色。显式传入`{}`表示不覆盖任何群系。

输入描述保存文件、固定映射范围、颜色→群系ID和容差；请求快照与工作进程不携带UE对象。图像内容、色板或容差变化进入生成身份；没有分布图时保持原生成行为。绑定时一次识别成不可变整数类别图，后续不保留每群系权重图。

## 可运行示例

在模组目录使用UE Python执行，输出目录须为新目录：

```powershell
& 'D:/UE_5.8/Engine/Binaries/ThirdParty/Python3/Win64/python.exe' -B -X utf8 examples/biome_map_workflow.py --output 'E:/ue/Mineprep_5_8/Intermediate/MyBiomeMap'
```

示例生成起伏高度图、透明分区PNG、带±16色差的PNG、色板、WorldSpec、容差32／0对照预览及识别统计；容差32的带噪输入与原色图生成相同群系和地表。另有可选UE放置脚本，默认使用原色图。预览不代表实际UE渲染验收；引擎内可查看森林／沙漠边界、材质、植被及固定LOD。

分类绘图示例使用同一个纯数据画布，绘制森林、沙漠并擦出自动选择的通道，验证撤销重做后输出相同：

```powershell
& 'D:/UE_5.8/Engine/Binaries/ThirdParty/Python3/Win64/python.exe' -B -X utf8 examples/biome_paint_workflow.py --output 'E:/ue/Mineprep_5_8/Intermediate/MyBiomePainting'
```

输出`painted.png`及`painted.palette.json`、绘图叠加层、生成前后预览和WorldSpec。源代码见[示例](../examples/biome_paint_workflow.py)，通用绘图和RT验证见[地图绘图](PAINTING.md)。
