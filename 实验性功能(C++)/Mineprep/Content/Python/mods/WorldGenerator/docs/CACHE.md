# 缓存与参数依赖

格式3的 `i18n.json` 不进入包文件戳、内容／生成指纹或模块源码快照。展示文本在加载与显式刷新时读取，编辑器仅按秒检查文件戳；详见[本地化](LOCALIZATION.md)。

2026-10-20 核心数据流重构后的现状。一次生成内的数据只算一遍，然后丢弃；跨生成保留的只有下表几项。

## 一次生成内

| 数据 | 范围 | 说明 |
| --- | --- | --- |
| 二维字段库 `core/store.py` | 输出区域 + 包推出的外边距 | 参考地表（高度、水位、湿格、群系、地表方块）与全部已算字段只算一遍；实体 tile、景观、列景观、表面处理、洞穴／流体的地表查询都切片读取。生成结束即释放 |
| 整区处理 `@region_pass` | 工作域 + 下游 `halo + margin`（或显式固定 `region`） | 不依赖资源的 Pass 在 `planning` 前算一次，依赖资源的在 `planning` 后算一次；进程任务按条带／分块窗口裁剪传输，实体阶段直接复用字段库切片 |
| 三维密度格点块 | 同一进程内同一生成 | `density.task_scope(key)` 共享 32 格世界对齐块的格点与规则采样；进程只保留最近一次生成的块 |

字段库之外的地表查询（洞穴通道锚点、体积查询等）由 `planning.SurfaceTiles` 按 128² 世界对齐块求值，每进程最多保留 4096 个 64² 瓦片。

固定核心分区使用一个外围精度字段库，精细核心以局部1格字段覆盖；留空不计算核心细字段。宏观规划与整区处理只执行一次。`MixedStore` 是请求内的读取视图；混合查询在活动字段库中切片，库外从同一组单精度源求值，不写入旧的单精度地表缓存。局部任务的步长只决定输出块尺寸，参考源始终按布局的外围步长与核心范围选择。

## 跨生成保留（每进程）

| 数据 | 上限 | 身份 |
| --- | --- | --- |
| 内容包加载 | 32 项 | 文件戳；私有源码快照在会话内保留 |
| 规划资源（水系、洞穴、玄武岩、岩柱） | 8 项，最近使用优先 | 种子、生成内容指纹及 `planning_params` 声明的参数；主世界洞穴布局还区分水平精度和粗算法版本（若包内含未固定 `region` 的 `@region_pass`，还包含请求 `region`） |
| 规划对象内的锚点／单元记录 | 不淘汰，随规划对象释放 | 世界坐标锚点，与输出裁切无关 |
| 地下水窗口、地表水连通 | 各 512 项 | 同上，并区分水平精度和粗生成算法版本 |
| 高度图解码 | 2 份 | 内容 SHA、采样版本与映射 |
| World／输出准备 | `ops` 中各 2 项 | 请求、来源与输出配置 |

多进程时，主进程把提前算好的水系规划随任务发给 worker（`Resources.shared`），惰性规划在 worker 内按需构建。

## `planning_params` 声明

`pack.json` 可选 `planning_params`，把规划资源映射到参数选择列表，未列出的参数改动可复用该资源：

```json
{"planning_params": {"water": ["world.*", "terrain.*", "seabed.*",
  "hydrology.*", "river.*", "lakes.*", "ponds.*", "water.generate"]}}
```

键为已声明的 planner 名，或核心的 `surface`／`density`。选择项为精确参数名或 `section.*` 前缀，加载时展开、排序、去重；未知资源、无匹配项及非法类型报错。空列表表示确实不依赖参数。声明只作用于当前包，**不随 extends 继承**；未声明时保守使用全部生成参数。所有键仍包含种子、算法和完整生成内容指纹。

原版声明的效果：植物、洞穴和表面覆盖编辑复用水系；植物与地下水编辑复用干洞穴规划；改 `groundwater.connect_surface` 会让最终密度失效。下界的岩柱、熔池、柱簇规划不受火、矿物、材质和输出裁切影响。

2／4格的密度及规划资源键默认包含 `cell_step` 与 `coarse.VERSION`，覆盖洞穴、地下水、连接、下界岩柱／熔池／柱簇以及自定义规划器，防止对象保留其他精度的Pack或查询器。已审阅的纯宏观 `water` 资源继续共享；`surface` 源仍由SurfaceTiles单独区分步长。0.69.0不再依靠几种几何规划器的名字白名单决定隔离；自定义宏观规划器保守隔离，不推断其独立于精度。没有新增缓存层，1格键保持既有结构，世界输出身份包含粗算法版本；内容包源码变动仍更新内容指纹。

0.67.0 固定分区的世界身份增加 `layout.VERSION`、规范化后的完整核心角点和留空模式；准备结果继承世界身份。0.70.0将实际交集、外围步长、留空及布局算法身份加入混合密度和规划资源键，主世界洞穴、下界岩柱／熔池／柱簇及自定义持有几何查询的对象都按布局隔离；同一请求内的细／粗任务使用相同布局身份。0.71.0地下水及湖海连接沿用这一身份，连接规划始终读取完整分区，批准开口在混合基础密度映射后应用。已审阅的宏观水系资源及纯单精度二维源继续复用；混合结果不写入旧的单精度瓦片缓存，没有新增缓存层。

## 编辑与准备

0.71.1更新现有`coarse.VERSION`以隔离局部表面拆分前后的粗生成与准备结果；不增加缓存层，1格世界身份保持原规则。

- 预设菜单、默认预设属于显示元数据，不改变已解析参数相同的几何身份。
- 方块材质（emission、lighting）、植被颜色、BCT 色板与乘方只影响准备与资源身份，World 与预览保留。
- 预览高度、剖面位置只重画已有 World。
- 资源命中仍检查引用完整性与纹理就绪；详见 [OUTPUT](OUTPUT.md)。
