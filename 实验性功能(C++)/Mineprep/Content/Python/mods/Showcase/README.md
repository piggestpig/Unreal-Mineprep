# 内容展示

这是界面参考图库，不是功能模组。图片只供对照控件长什么样，可能没有及时更新。

做界面前直接查看 `image/` 里的文件，不必启用本模组。文件名用序号加画面名，例如 `01_utility_tools_sprite.png`，只收 png、jpg、jpeg。`image/` 不随模组打包。

手动启用后会打开轮播面板，按文件名顺序显示这些图片。文件名居中在顶上，左右三角按钮或键盘左右键切换，到第一张或最后一张就停下。名称和图片中间有进度滑条，翻页时跟着移动，拖动它也会换页。Pause/Break 打开文件夹，小键盘加号不截自己。默认不启用，也不会随 Mineprep 重载而导入。
